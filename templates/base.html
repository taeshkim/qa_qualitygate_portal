🔔 OS 알림이 안 뜰 때 체크리스트
테스트 버튼을 눌렀을 때 토스트만 뜨고 OS 알림이 안 보인다면 아래 3단계 확인.
🍎 macOS
  1. 시스템 설정 → 알림 → Google Chrome
    • "알림 허용" ON
    • "알림 스타일" 배너 또는 경고 (없음이면 안 뜸!)
    • "알림 센터에 표시" ON
  2. 집중 모드 OFF
    • 메뉴바 우측 제어 센터 → 달🌙 아이콘이 파란색이면 클릭해서 끔
    • 시스템 설정 → 집중 모드 → 자동 규칙 전부 해제
  3. 화면 미러링/공유 중이면 macOS가 자동 차단 → 해제
  4. 배너는 화면 우측 상단에 뜸 (하단 아님!)
🪟 Windows
  1. 설정 → 시스템 → 알림 → Google Chrome
    • Chrome 토글 ON
    • "알림 배너 표시" ON (OFF면 트레이에만 쌓임)
    • "알림 센터에 알림 표시" ON
  2. 방해 금지 모드(집중 지원) OFF
    • 알림 센터 상단 🌙 아이콘이 파란색이면 클릭해서 끔
    • 자동 규칙(시간대/게임/전체화면) 전부 해제
  3. 전체화면(F11) 상태면 숨김 — 설정에서 "전체화면 모드에서 알림 숨기기" OFF
🌐 공통 (브라우저 쪽)
  1. 주소창 왼쪽 🔒 자물쇠 → 사이트 설정 → 알림 → 허용
  2. chrome://settings/content/notifications → "조용한 메시지 사용" OFF
  3. 사이트 상단에 노란 배너가 보이면 클릭해서 권한 요청
⚠ 참고 — Chrome 탭 자체를 완전히 닫으면 알림 안 옴 (JS가 안 돌아서). 백그라운드 탭으로 두거나 최소화는 OK.
